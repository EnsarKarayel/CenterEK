# CenterEK erişim e-postası taslağı

Durum: Gönderilmeye hazır değil. Gerçek HTTPS adresi ve dış giriş testleri
tamamlandıktan sonra köşeli parantezli alan doldurulmalıdır. Bu dosya parola içermez.

**Konu:** CenterEK test paneli — erişim bağlantısı ve kullanım

Merhaba,

CenterEK test paneline bilgisayarınıza program kurmadan tarayıcınızdan erişebilirsiniz:

**[DOĞRULANMIŞ AZURE HTTPS ADRESİ BURAYA EKLENECEK]**

1. Bağlantıyı güncel Edge, Chrome veya Firefox ile açın.
2. Erişim izni verilen Microsoft hesabınızla oturum açın. Varsa çok faktörlü
   doğrulamayı tamamlayın. Her Microsoft hesabı kendiliğinden yetkili değildir.
3. CenterEK giriş ekranında size tanımlanan kişisel panel hesabıyla giriş yapın.
   Panel hesabı, Windows veya Azure yönetici hesabı değildir.
4. Paylaşılan bir bilgisayardan ayrılırken CenterEK'ten ve Microsoft oturumundan
   çıkın. Parolayı ortak bilgisayara kaydetmeyin.

Bu bir test ortamıdır. Ofis ağındaki cihazların görünmesi için ilgili ajanların
ve özel ağ bağlantılarının ayrıca kurulmuş olması gerekir. Müşteri kurulumları
kendi verilerini, hesaplarını ve cihaz bağlantılarını ayrı tutacaktır.

Erişim sorunu yaşarsanız ekrandaki hata metnini iletin. Parola, API anahtarı,
doğrulama kodu veya müşteri verisi göndermeyin.
